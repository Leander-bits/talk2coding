# 任务：让默认启动录音、转写并生成 prompt

状态：首版功能已实现，本机模型和集成结果见下方。日期为 2026-11-22。

## 目标与验收

- 将原先的设备枚举入口改为实际录音会话。默认按住 F7 说话，松开显示 Whisper 转写，按 Enter 合并当前段落并生成 prompt。
- 保留帮助与设备诊断。用户已有的项目 `.env` 中，`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`MODEL_NAME` 可直接供 OpenAI SDK 使用。
- [x] 验证默认命令进入会话，设备诊断可独立退出，释放时流关闭，丢帧保留先前有效段。
- [x] 以真实 SDK 和模拟 HTTP 验证请求路径、正文、响应边界和显式重试。
- [ ] 在 VS Code 中用经同意的人声验证按键焦点、准确率和端到端体验。付费 API 需单独授权。

## 计划与授权

- [x] 复核当前骨架、选型、SDK 和环境兼容性。
- [x] 实现单文件录音会话、配置读取、模型缓存和文本生成，运行单元及组件检查。
- [x] 更新开发、架构和双语 README。
- 用户要求使用 OpenAI Python SDK，已安装项目本地依赖 `openai 3.57.0`。实际 Whisper 权重使用项目内被忽略的 `.local/whisper/`。工作期间没有打开用户的 `.env` 或用其中的凭证发请求。
