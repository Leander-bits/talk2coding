# Agentic Coding Project Template

[简体中文](README.md) | English

## Introduction

A shared project template for Codex and GitHub Copilot, covering development rules, code organization, verification, and authorization. Describe requirements and confirm decisions in chat; AI writes the code and maintains the relevant documentation.

General rules support different technology stacks. Python projects also use workflow functions, prohibit nested function definitions, define a `main()` entry point, and split files according to complexity. Both tools share one core rule source; a script generates the Copilot copy.

Use the Chinese [step-by-step prompts](docs/PROMPTS.md) to start and iterate. See the [GitHub guide](docs/GITHUB.md) for publishing and reuse, and [references](docs/REFERENCES.md) for design sources. The template uses the [MIT license](LICENSE). Instructions are working agreements; client permissions, sandboxing, and CI provide separate controls.

## Structure

```text
.
├── AGENTS.md                         # Canonical core rules
├── README.md / README.en.md          # Chinese / English, linked versions
├── LICENSE                          # MIT
├── .editorconfig                    # Encoding, indentation, line endings
├── .gitattributes                   # Git text line endings
├── .gitignore                       # Local secrets and generated files
├── .github/
│   ├── copilot-instructions.md      # Generated by AI from AGENTS.md
│   ├── pull_request_template.md     # PR purpose, checks, risks
│   └── workflows/template-checks.yml # Instruction consistency check
├── scripts/sync_instructions.py     # Run by AI when rules change
└── docs/
    ├── PROMPTS.md                   # Start, test, fix, and iterate
    ├── PROJECT.md                   # Goals, scope, constraints
    ├── DEVELOPMENT.md               # Actual commands, setup, verification
    ├── ARCHITECTURE.md              # Entry point, structure, decisions
    ├── TASK_TEMPLATE.md             # Complex task record template
    ├── GITHUB.md                    # Publish and create new projects
    └── REFERENCES.md                # Sources and design choices
```

No application layout or stack is preselected. AI chooses a single-file or multi-file structure during implementation and creates `docs/tasks/` when task records are needed. Documentation other than this English README remains in Chinese.
